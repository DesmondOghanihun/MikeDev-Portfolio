## Project Name: MikeDev Portfolio Highlights
**A high-performance, responsive React portfolio template built with Vite.**
### 📝 Project Summary
This project is a modern personal showcase designed to highlight technical projects with a focus on UI/UX precision. It features a dynamic gallery that renders project data through reusable components and a fully functional, state-managed contact section. By leveraging React’s modern hook-based architecture, the application ensures a smooth, single-page experience (SPA) for visitors.

### 🏗️ Architecture & Folder Structure

Your project follows the standard professional React structure:

* **`src/`**: The core of the application, containing `App.jsx` (logic) and `main.jsx` (entry point).
* **`public/`**: Static assets like the `favicon.ico`.
* **`dist/`**: The production-ready build generated by Vite, optimized for fast deployment.
* **`vite.config.js`**: Configuration for the lightning-fast development environment and build tool.

### 🚀 Key Technical Features

#### 1. Component-Driven Design

The application uses a modular **`ProjectCard`** sub-component. This allows for a "DRY" (Don't Repeat Yourself) codebase where the UI for each project is defined once but reused for multiple data points.

#### 2. Dynamic Data Rendering

Instead of hard-coding HTML, the project uses the JavaScript `.map()` method to loop through a `PROJECTS` array. This makes the portfolio incredibly easy to update—just add a new object to the array, and the UI updates automatically.

#### 3. Controlled Form State Management

The "Get In Touch" section demonstrates advanced React state handling:

* **Real-time Synchronization**: Uses a single object state `formData` to track name, email, and message inputs.
* **Dynamic Updating**: A universal `handleChange` function uses computed property names `[name]: value` to update state based on the input's `name` attribute.
* **Client-Side Validation**: Implements logic to intercept form submission, validate email formatting, and prevent default browser behavior via `e.preventDefault()`.

### 🛠️ Tech Stack

* **Frontend Library:** React 18
* **Build Tool:** Vite (for near-instant Hot Module Replacement)
* **Styling:** CSS3 (Custom properties, Flexbox, and CSS Grid for the gallery)
* **Language:** JavaScript (ES6+)
